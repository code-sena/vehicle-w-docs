# Events — Notification Service

## Consumed

Queue `notification-service.events` bound to `carwash.events` (DLQ `notification-service.events.dlq`;
3 retries, then dead-lettered). Each publisher sends the recipient's `user_id` (ADR-011 §3).

| Routing key | Event | Notification | Email |
|---|---|---|---|
| `security.user_registered` | `UserRegistered` | `USER_WELCOME` | yes (address in the event) |
| `booking.created` | `BookingCreated` | `BOOKING_CREATED` | yes |
| `booking.confirmed` | `BookingConfirmed` | `BOOKING_CONFIRMED` + schedules reminders | yes |
| `booking.cancelled` | `BookingCancelled` | `BOOKING_CANCELLED` + cancels reminders | yes |
| `execution.operator_assigned` | `OperatorAssigned` | `OPERATOR_ASSIGNED` | no |
| `execution.service_started` | `ServiceStarted` | `SERVICE_STARTED` (and cancels the pending reminders, ADR-011 §13) | no |
| `execution.service_completed` | `ServiceCompleted` | `SERVICE_COMPLETED` (and cancels the pending reminders) | no |
| `payment.confirmed` | `PaymentConfirmed` | `PAYMENT_CONFIRMED` | yes |
| `payment.rejected` | `PaymentRejected` | `PAYMENT_REJECTED` | yes |
| `payment.refunded` | `PaymentRefunded` | `PAYMENT_REFUNDED` | yes |
| `payment.promotion_redeemed` | `PromotionRedeemed` | `PROMOTION_REDEEMED` | yes |
| `payment.loyalty_points_earned` | `LoyaltyPointsEarned` | `LOYALTY_POINTS_EARNED` ("Ganaste N puntos") | no |
| | | `PROMOTION_AVAILABLE` ("¡Tienes un cupón canjeable!"), one per entry in `unlockedPromotions` | yes |

security-service, booking-service, operations-service and payment-service publish. Booking events
also produce the staff notifications of ADR-011 §10 (inbox and push only, never email).

Customer emails and reminders read the current address from security-service
(`GET /internal/v1/users/{id}/contact`, ADR-011 §8); without it they still reach the inbox and push.

## Sent by the administrator

`POST /api/v1/admin/notifications` (`userIds`, optional `type`, `title`, `message`; ADMIN only)
applies the same email rule as events. Only these two types are accepted; any other one answers 400
`NOTIFICATION_TYPE_NOT_ALLOWED` (event-only types cannot be written by hand):

| Type | Use | Email |
|---|---|---|
| `SYSTEM_MESSAGE` (default) | Free announcement ("we close early today") | no |
| `INSPECTION_REPORT` | Inspection screen, "Notificar al cliente": summary of the vehicle inspection (ADR-011 §11) | yes |

## Generated by time

| Trigger | Notification |
|---|---|
| Reminder task (every `REMINDER_CHECK_INTERVAL`) | `BOOKING_REMINDER` 24 h and 1 h before each booking (inbox, push, email) |
